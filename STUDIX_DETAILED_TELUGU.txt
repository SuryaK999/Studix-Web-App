1. MANA PROJECT YEOKKA MAIN AIM (Concept):
------------------------------------------
* Integrated Workspace: General ga students study chesetappudu chat ki okati, 
  notes ki okati, and doubts ki inkoka app vaadtaru. Vaati valla focus potundi. 
  Studix lo anni okate "Study Room" lo integrated ga untayi.
* Real-Time Collaboration: "Zero Lag" interaction. Evaru em chesina ventane 
  room lo unna migata vallaki fraction of seconds lo update avvali.
* AI-Enabled Tutoring: Study madhyalo doubts vaste bayataki vellakunda, 
  app loni "Study Buddy" AI help teesukovachu.

2. TECH STACK - FULL DEEP DIVE (Inka detail ga):
------------------------------------------------
Manam deenni "HYBRID STACK" antunnam. Endukante standard MERN kakunda specialist 
tools vaadam:

* FRONTEND (React + Vite + Tailwind):
  - React: Build cheyadam fast ga untadi and components reuse cheyochu.
  - Framer Motion: Deep animations and transitions kosam.
  - Radix UI: Accessible components like Dialogs and Popovers kosam.
  - Zustand: Global state management. Redux kanna idi chala light and fast.

* BACKEND (Node.js + Express):
  - Node.js: Event-driven architecture. Enno real-time connections ni handle 
    cheyadaniki idi best language.
  - Socket.IO: Multi-user communication (chat & typing indicators) kosam.

* DATABASE (The Hybrid Logic):
  - MongoDB (Primary): Users, Rooms, and persistent Chat history database.
  - Firebase Firestore: Tasks and AI-chat history sync cheyadaniki.
  - Redis (Upstash): Users online status ni manage cheyadaniki (Memory store).

* STORAGE & STATS:
  - Supabase Storage: PDFs and Photos cloud lo store cheyadaniki.
  - Firebase Auth: Login security and JWT token management.
