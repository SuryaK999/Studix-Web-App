🏗️ The Studix Master Stack (Accurate Breakdown)
Each part of the app is specialized for speed and reliability:

Frontend: React (Vite) + Tailwind CSS + Framer Motion.
Used for: The premium, animated Discord-grade UI.

Authentication: Firebase Auth.
Used for: Login, signup, and secure session management.

Primary Database (Rooms & Messaging): MongoDB Atlas.
Used for: Storing study rooms, memberships, and persistent chat logs. (Shifted from Firebase to allow Discord-style channel structures).

Secondary Database (Tasks & AI Chat): Firebase Firestore.
Used for: Real-time task syncing and AI Study Buddy message history.

Real-Time Presence: Socket.IO + Upstash Redis.
Used for: The "Who's Online" green dots and instant typing indicators across different computers.

Cloud Storage: Supabase Storage.
Used for: PDF uploads, photos, and user profile images.

Backend API: Node.js & Express (running on Port 4000).
Used for: The bridge that connects your login (Firebase) to your data (MongoDB).
