================================================================================
  FILE 2: app/server/.env   (Backend — Node.js)
================================================================================

Paste these into: d:\Studix\app\server\.env

------------------------------------------------------------------------
# SERVER PORT
------------------------------------------------------------------------
PORT=4000

------------------------------------------------------------------------
# MONGODB   ← NEW — REQUIRED
# Option A: Local MongoDB (install from https://www.mongodb.com/try/download/community)
# Option B: MongoDB Atlas (free cloud — https://cloud.mongodb.com)
------------------------------------------------------------------------
MONGO_URI=mongodb://localhost:27017/studix

# Atlas example:
# MONGO_URI=mongodb+srv://USERNAME:PASSWORD@cluster0.xxxxx.mongodb.net/studix?retryWrites=true&w=majority

HOW TO GET MONGO_URI (Atlas — free tier):
  1. Go to https://cloud.mongodb.com
  2. Create free account → Create cluster (M0 Free)
  3. Database Access → Add database user (username + password)
  4. Network Access → Add IP Address → Allow from anywhere (0.0.0.0/0)
  5. Cluster → Connect → Drivers → Copy the connection string
  6. Replace <username> and <password> with your values
  7. Replace "myFirstDatabase" with "studix"

------------------------------------------------------------------------
# FIREBASE ADMIN SDK   ← NEW — REQUIRED for login verification
# Source: Firebase Console → Project Settings → Service Accounts → Generate new private key
------------------------------------------------------------------------
FIREBASE_PROJECT_ID=your-firebase-project-id

# OPTION A (RECOMMENDED): Save the downloaded JSON file as:
#   d:\Studix\app\server\serviceAccountKey.json
# Then set:
GOOGLE_APPLICATION_CREDENTIALS=./serviceAccountKey.json

# OPTION B: Base64-encode the JSON file (PowerShell):
#   [Convert]::ToBase64String([System.IO.File]::ReadAllBytes("serviceAccountKey.json"))
# Then paste the output here:
# FIREBASE_SERVICE_ACCOUNT_BASE64=

HOW TO GET FIREBASE SERVICE ACCOUNT KEY:
  1. Go to https://console.firebase.google.com
  2. Select your project
  3. Click gear icon → Project Settings
  4. Go to "Service Accounts" tab
  5. Click "Generate new private key"
  6. Download the JSON file → save as server/serviceAccountKey.json

------------------------------------------------------------------------
# CORS — must match your frontend URL
------------------------------------------------------------------------
CLIENT_ORIGIN=http://localhost:5173
# For production: CLIENT_ORIGIN=https://your-frontend-domain.com

------------------------------------------------------------------------
# REDIS (OPTIONAL — app works without it)
# Enables: Socket.IO multi-server scaling, Redis presence, rate limiting
# Without Redis: everything still works using in-memory fallback
------------------------------------------------------------------------
REDIS_ENABLED=false
REDIS_URL=redis://localhost:6379

# For Redis Cloud (free tier at https://redis.io/try-free):
# REDIS_URL=redis://default:YOUR_PASSWORD@your-host.redis.cloud:PORT
# REDIS_ENABLED=true

HOW TO GET REDIS URL (Redis Cloud — free 30MB):
  1. Go to https://redis.io/try-free
  2. Sign up → Create free database
  3. Go to your database → Configuration → Copy "Public endpoint"
  4. Format: redis://default:PASSWORD@HOST:PORT

------------------------------------------------------------------------
# RATE LIMITING (tunable)
------------------------------------------------------------------------
CHAT_RATE_LIMIT_MAX=20
CHAT_RATE_LIMIT_WINDOW_SECONDS=5

================================================================================
  ARCHITECTURE SUMMARY (what each credential is used for)
================================================================================

  Firebase API Key (VITE_FIREBASE_*)
    → Client signs in, gets an ID token
    → Used in: Login/Signup forms, AuthContext

  Firebase Admin SDK (serviceAccountKey.json)
    → Server verifies that the ID token is real and not forged
    → Used in: server/middleware/auth.js (runs on every Socket.IO connect)

  MongoDB (MONGO_URI)
    → Stores: chat messages, room notes
    → Used in: server/models/Message.js, Note.js, User.js

  Supabase (VITE_SUPABASE_*)
    → Stores: uploaded images, files, voice messages
    → Used in: src/lib/storage/storageService.ts

  Redis (REDIS_URL) — OPTIONAL
    → Powers: Online presence tracking, typing indicators,
               chat rate limiting, multi-server Socket.IO
    → Used in: server/services/presence.js, rateLimiter.js,
               server/config/redis.js

  Gemini API Key — OPTIONAL
    → Powers: AI Study Buddy chat feature
    → Used in: src/components/ai/AiStudyBuddy.tsx
